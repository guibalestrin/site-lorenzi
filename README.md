# Casa Lorenzi

Site conceitual da Casa Lorenzi (case de estudo): um filme de 16 segundos que acompanha a rolagem e, abaixo dele, as peças por ocasião, o guia de caimento, o atendimento por consultora, as lojas, as trocas e as perguntas.

- `site/`: a pasta publicada. HTML, CSS e JavaScript puros, sem build.
- `site/assets/logo-casa-lorenzi.svg`: o logo oficial redesenhado em vetor.
- `assets-cdn.json`: os endereços do vídeo e das fotos, hospedados no armazenamento do Higgsfield.
- `pacote-de-design.md`: roteiro, textos, paleta e decisões de design.

Na Vercel, o projeto publica a pasta `site/` como site estático (Root Directory: `site`, sem comando de build).
